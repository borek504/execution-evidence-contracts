# Glossary

1. **Record**: The candidate's untrusted report.
2. **Expected**: Identities and policy established independently before execution.
3. **Verifier Context**: Separately supplied observations whose origin a real integration must establish.
4. **Attempt ID / Unit ID**: Identifiers used to match inputs to the intended attempt and unit, not authentication credentials.
5. **Digest / SHA-256**: A binding to contents, not a signature or proof that observations are true.
6. **Valid** versus **Qualification Authorized**: Data consistency is not permission to execute, qualify or release.
