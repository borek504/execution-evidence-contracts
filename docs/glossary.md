# Validator Glossary

This glossary defines key terminology used throughout the Execution Evidence Contracts validator:

### 1. 
ecord
The candidate untrusted report submitted for validation.

### 2. expected
The predefined identities and validation policies established independently before execution begins.

### 3. erifier_context
Separately supplied runtime observations whose origin and trust must be verified by the integrating system.

### 4. ttempt_id / unit_id
Identifiers used to correlate reports and observations to the intended attempt and unit, rather than authentication credentials.

### 5. Digest / SHA-256
A structural binding mechanism to document content integrity, not a digital signature or cryptographic proof of observation veracity.

### 6. alid vs. qualification_authorized
Structural data consistency (alid) verifies conformant format, whereas qualification_authorized is an independent authorization policy to permit execution, qualification, or release.
