# Glossary

- **Record**: The candidate's untrusted report.
- **Expected**: Identities and policy established independently before execution.
- **Verifier Context**: Separately supplied observations whose origin a real integration must establish.
- **Attempt ID / Unit ID**: Identifiers used to match inputs to the intended attempt and unit, not authentication credentials.
- **Digest / SHA-256**: A binding to contents, not a signature or proof that observations are true.
- **Valid** versus **Qualification Authorized**: Data consistency is not permission to execute, qualify, or release.
