# Glossary

1. **record**: The candidate's untrusted report.
2. **expected**: Identities and policy established independently before execution.
3. **verifier_context**: Separately supplied observations whose origin a real integration must establish.
4. **attempt_id** / **unit_id**: Identifiers used to match inputs to the intended attempt and unit, not authentication credentials.
5. **Digest / SHA-256**: A binding to contents, not a signature or proof that observations are true.
6. **valid** versus **qualification_authorized**: Data consistency is not permission to execute, qualify, or release.
